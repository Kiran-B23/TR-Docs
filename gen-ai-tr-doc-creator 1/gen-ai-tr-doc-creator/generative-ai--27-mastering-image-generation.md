## Understanding Image Generation Types

AI image generation can be categorized into three main transformation types.

### Text-to-Image Generation

- Takes text descriptions as input and generates corresponding images as output
- Example: you type "sunset over mountains," and the AI paints it for you

### Image-to-Text

- Takes images as input and generates descriptive text as output
- Example: describing a photo as "a cat sitting on a chair"

### Image-to-Image

- Transforms one image into another based on style, content, or specific modifications
- Example: turning a sketch into a realistic version, or restyling an existing photo

## Closed Source & Open Source Models

Within the AI community, there are two approaches, and image generation has both.

- **Closed approach**: Models are not fully publicly accessible. They are developed and maintained by organizations or companies, and you access them via certain interfaces like mobile apps, web apps, or APIs.

- **Open source approach**: Publicly available models that allow anyone to use, modify, and work with the software.

## Image Generation Best Practices

The prompt is everything. Whether you're making an image, editing one, or describing one, a clear prompt gives you a much better result.

- **Write a full sentence, not keywords** – describe the whole scene so the model sees how things connect (say "a cat sitting on a red sofa near a sunny window," not "cat, sofa, sun").
- **Start with the subject** – say who or what the image is about first, and what it looks like.
- **Then add setting → materials → lighting → composition** – the background, the textures, the light, and the camera angle or framing.
- **Open with your intent** – begin with "Create an image of…" (to make one) or "Look at this image and tell me…" (to describe one) so the model knows what you want.
- **Say what you want in a positive way** – "an empty street" works better than "no cars."
- **Keep it tight** – around 15–50 words is plenty; every word should add something.
- **Refine step by step** – start simple, then improve with small follow-ups like "make the lighting warmer," instead of rewriting the whole prompt.
- **Stuck?** Ask an LLM to expand your idea into a detailed prompt, then tweak it.

**The order to build a prompt in:**

`Subject → Setting → Materials / Textures → Lighting → Composition (angle & framing)`

<MultiLineNote>
AI image tools are evolving fast. Even different versions of the same model (e.g., "flash" vs. "pro") can vary in quality. If your first result looks off — odd proportions, strange hands — that's normal. Just retry or refine your prompt.
</MultiLineNote>

| Best practice | Where it appears |
|---|---|
| Open with intent | Starts with "Create an image of…" — tells the AI to make, not describe |
| Subject first | "a calm tropical beach at sunset" |
| Full sentences | The whole scene is described in connected sentences, not keywords |
| Positive language | Says what should be there (golden sun, gentle waves, palm trees), never what shouldn't |
| Composition | "Shoot it like a wide, cinematic photograph" sets the framing and camera feel |

## Adding Image to Social Media Automation Workflow

**Recall: Building Social Media Workflow**

We built a workflow that turns an article into a LinkedIn post — text only.

`Article → Extract → Understand → Structure → Rewrite → Finalize → LinkedIn post`

The nodes we had were:

`Google Sheets Trigger → Summarize Article → Create LinkedIn Post → Post to LinkedIn`

(with a Google Gemini Chat Model attached to each of the two AI nodes)

**The Idea**

A post with a matching image gets noticed more. Let's enhance that same workflow to generate and attach an image.

`Article → Extract → Understand → Structure → Rewrite → Generate Image → Finalize → LinkedIn post`

The updated node chain:

`Google Sheets Trigger → Summarize Article → Create LinkedIn Post → Generate Image Prompt → HTTP Request → Post to LinkedIn`

(with a Google Gemini Chat Model attached to each of the three AI nodes)

**Updated Steps**

| # | n8n node | What it does |
|---|---|---|
| 1 | Google Sheets Trigger | Starts on a new article link *(had it)* |
| 2 | Google Gemini | Summarizes the article *(had it)* |
| 3 | Google Gemini | Writes the LinkedIn post *(had it)* |
| 4 | Google Gemini | Writes an image prompt *(new)* |
| 5 | HTTP Request → Stability AI | Generates the image *(new)* |
| 6 | LinkedIn | Posts the text AND the image |

A text model writes the prompt · an image model makes the picture.

<MultiLineNote>
The HTTP Request node both generates and downloads the image. Setting its **Response Format** to `File` makes the node return the generated image as binary data, so no separate download node is needed.
</MultiLineNote>

### Step-by-Step Guide

<details>
<summary><strong>Step 1: Google Sheets Trigger</strong></summary><br/>

This is the same trigger from the previous unit — reuse it as-is.

- Add a new node → `Google Sheets Trigger`
- Select the OAuth2 credential you created earlier
- Set `Poll Times` → `Mode`: `Every Minute`
- `Document`: select your sheet from the list (e.g. `socialmedia workflow`)
- `Sheet`: select the tab holding your links (e.g. `Sheet2`)

<MultiLineNote>
n8n triggers the workflow only for new or updated rows since the last check, not for every row in the sheet.
</MultiLineNote>

</details>

<details>
<summary><strong>Step 2: Summarize Article</strong></summary><br/>

- Add a new node → `Basic LLM Chain`
- Name it `Summarize Article`
- Set `Source for Prompt` → `Define below`
- Add the **prompt**:

```
summarize this article {{ $json.newslink }}
```

- Click the `+` under the chain to add a model → `Google Gemini Chat Model`
- Click `Create New Credential` and paste your Google AI Studio API key
- Set `Model`: `models/gemini-3.1-flash-lite`
- Connect `Google Sheets Trigger` → `Summarize Article`

</details>

<details>
<summary><strong>Step 3: Create LinkedIn Post</strong></summary><br/>

- Add another `Basic LLM Chain` node
- Name it `Create LinkedIn Post`
- Set `Source for Prompt` → `Define below`
- Add the **prompt**:

```
Assume the role of an Industry expert and create a ready-to-post LinkedIn content discussing key points from the provided news article relevant to artificial intelligence. The post should provide insightful analysis, connect with current industry trends, and encourage professional engagement. Highlight notable implications for the industry and include a professional call to action.
Make the post informative, structured, under 3000 characters, and ready to copy-paste directly to LinkedIn without any modifications.
Article summary: {{ $json.text }}
```

- Add a `Google Gemini Chat Model` and select the credential you already saved
- Connect `Summarize Article` → `Create LinkedIn Post`

</details>

<details>
<summary><strong>Step 4: Generate Image Prompt (new)</strong></summary><br/>

This is where image generation begins. A **text** model writes the prompt that the **image** model will use.

- Add another `Basic LLM Chain` node
- Name it `Generate Image Prompt`
- Set `Source for Prompt` → `Define below`
- Add the **prompt**:

```
Create a concise image prompt (max 50 words) for a LinkedIn post visual based on this AI article summary. Focus on modern, professional imagery with technology/business themes. Use clear descriptive terms suitable for AI image generation. {{ $json.text }}
```

- Add a `Google Gemini Chat Model` and select the credential you already saved
- Connect `Create LinkedIn Post` → `Generate Image Prompt`

<MultiLineNote>
Notice this prompt applies the best practices we learned: it asks for descriptive terms rather than keywords, and caps the length at 50 words so every word counts.
</MultiLineNote>

</details>

<details>
<summary><strong>Step 5: HTTP Request — Generate the Image with Stability AI (new)</strong></summary><br/>

- Add a new node → `HTTP Request`
- Name it `HTTP Request`

The easiest way to configure it is to **import the cURL command**. Click `Import cURL` in the node and paste:

```bash
curl --request POST \
  --url https://api.stability.ai/v2beta/stable-image/generate/core \
  --header "Authorization: Bearer YOUR_API_KEY" \
  --header "Accept: image/*" \
  --form "prompt=YOUR_TEXT_PROMPT" \
  --form "output_format=jpeg" \
  --output image.jpeg
```

After importing, update the following settings:

**Headers**

| Name | Value |
|---|---|
| `Authorization` | `Bearer YOUR_STABILITY_API_KEY` |
| `Accept` | `image/*` |

**Body Content Type**

```
Form-Data
```

**Body Parameters**

| Type | Name | Value |
|------|------|-------|
| Form Data | `prompt` | `{{ $json.text }}` |
| Form Data | `output_format` | `jpeg` |

**Response Options**

| Field | Value |
|---|---|
| Response Format | `File` |
| Put Output in Field | `image.jpg` |

- Connect `Generate Image Prompt` → `HTTP Request`

<MultiLineNote>
According to Stability AI, the **Stable Image Core** endpoint requires the request body to be sent as **`multipart/form-data`**. Therefore, the `prompt` must be added as a **Form Data** field instead of a JSON or Form Urlencoded field.
</MultiLineNote>

<MultiLineWarning text="Important">
Generate your own Stability AI key from <a href="https://platform.stability.ai/account/keys" target="_blank">platform.stability.ai/account/keys</a>. Never share an API key or paste it anywhere public — anyone with the key can spend your credits.
</MultiLineWarning>

</details>

<details>
<summary><strong>Step 6: Post to LinkedIn (with the image)</strong></summary><br/>

- Add a `LinkedIn` node
- Name it `Post to LinkedIn`
- Select the LinkedIn OAuth2 credential you created earlier
- Configure the parameters:

| Field | Value |
|---|---|
| Person Name or ID | select your name from the list |
| Text | `{{ $('Create LinkedIn Post').item.json.text }}` |
| Share Media Category | `IMAGE` |
| Visibility | `PUBLIC` |

- Connect `HTTP Request` → `Post to LinkedIn`

<MultiLineNote>
`Share Media Category` must be set to `IMAGE` — this is what tells the LinkedIn node to attach the binary image coming from the HTTP Request node instead of posting text only.
</MultiLineNote>

<MultiLineNote>
The `Text` field pulls from `Create LinkedIn Post` rather than the previous node, because the previous node (`HTTP Request`) now carries the image, not the post copy.
</MultiLineNote>

</details>

<details>
<summary><strong>Step 7: Workflow Settings</strong></summary><br/>

- Open `Workflow Settings` (three dots at the top right)
- Ensure the workflow can carry binary data between nodes

The exported workflow uses:

```

    "executionOrder": "v1",
    "binaryMode": "separate"
}
```

</details>

### Common Issues you may Encounter

- **401 Unauthorized from Stability AI:** API key missing, mistyped, or missing the `Bearer ` prefix
- **400 Bad Request from Stability AI:** Body sent as JSON instead of `Form-Data`
- **LinkedIn posts text but no image:** `Share Media Category` is not set to `IMAGE`, or the binary field name in the LinkedIn node doesn't match the `Put Output in Field` value set on the HTTP Request node
- **Payment / credit errors:** Stability AI is credit-based — check your balance in the dashboard
- **Content Quality:** Prompts need refinement for better output

<MultiLineNote>
If the LinkedIn node cannot find the image, make the binary field names line up on both sides — either set the HTTP Request node's `Put Output in Field` to `data` (the LinkedIn node's default), or point the LinkedIn node's binary property at `image.jpg`.
</MultiLineNote>

## How Image Generation Models Work

### Core Training Process

- Image generation models learn by looking at millions of pictures
- While text-based AI systems learn from written content
- The model learns data patterns and relationships throughout its training process

They get trained to spot patterns — shapes, colors, styles — and link those patterns with descriptions. So when you give them a prompt, they recall those learned patterns and combine them to create something new.

### Input Processing

- **Text prompts**
    - The system tries to generate images that align with text prompts
- **Existing Images**
    - When you input existing images, the system modifies them to match your chosen style or concept

That's why you see tasks like text-to-image and image-to-image.

### Top Architectures Behind Image Generation

These architectures define how a particular image generation model works. Knowing the difference helps you understand why one model gives sharper images, another gives artistic ones, and another runs faster on your laptop.

- **Diffusion Models**
    - Start with noise and gradually refine it into a clear image
- **GAN (Generative Adversarial Network)**
    - Two AI systems compete — one creates images, one judges if they're real. Over time, the creator gets better by learning from the checker
- **VAE (Variational Autoencoder)**
    - Compress images into simple codes, then rebuild them from those codes — like a zip file for images, which helps models work faster
- **Transformer-based Models**
    - Focus on how different parts of an image relate to each other — like how the sun, sky, and sea connect in a sunset

<MultiLineNote>
These architectures are for your reference. Don't worry if the terms are new. The core point is that these are different engines that power AI image generation, and each one has its own strengths.
</MultiLineNote>

## Diffusion Models

- Diffusion models are one of the top choices for creating high-quality images from text descriptions

They are particularly good at capturing fine details and making images that look both realistic and artistic. Those super sharp AI artworks you see online — hyper-realistic portraits or fantasy-style landscapes — were very likely created by a diffusion-based system.

### How Diffusion Models Work

Let's understand the magic behind diffusion models!

These power most modern AI image generators, such as **Stable Diffusion** and **Flux AI**

Think of diffusion models as a step-by-step sculpting process. They don't create an image in one shot. Instead, they start with total chaos — random noise — and gradually shape that noise into a clear picture.

- Imagine you're looking at TV static — just random dots and noise
- Now imagine if you could slowly "clean up" that static, bit by bit, until it becomes a beautiful picture
    - At first, you'd notice faint outlines hidden inside
    - Then, as you keep cleaning, more shapes, colors, and details emerge
    - Finally, after enough steps, you'd have a complete picture
- That's exactly how diffusion models work!

<MultiLineNote>
**TV static** refers to the fuzzy, white-noise-like pattern seen on analog screens when there's no strong signal.
</MultiLineNote>

**Phases of Diffusion Models**

<details>
<summary><strong>1. Training Phase (Teaching the AI)</strong></summary>

- The AI learns by taking millions of real images
- It gradually adds "noise" to them (like adding static to a TV channel)
- It learns the reverse process: how to remove that noise step by step

A clear image — say, of a cat — slowly gets covered with more and more noise until it's completely unrecognizable. The AI then trains itself to go backwards, removing that noise step by step until the cat reappears. By repeating this across millions of examples, it becomes an expert at reversing noise and pulling structure back out of chaos.

</details>

<details>
<summary><strong>2. Generation Phase (Creating New Images)</strong></summary>

- Start with pure random noise (like TV static)
- The AI uses what it learned to gradually "denoise" this random pattern
- With each step, it removes a bit of noise and adds meaningful details
- After many steps (usually 20-50), you get a clear, beautiful image!
- AI-generated images take 10–30 seconds because the AI cleans random noise step by step into the clear, beautiful image!

Step 1: pure noise. Step 2: a faint outline appears. Step 3: more details come into focus. Step 4: a clear, sharp image. And the image isn't random — it matches the text prompt you gave.

</details>

**The Two Phases**

| | Training (done once) | Generation (every prompt) |
|---|---|---|
| **Direction** | Adds noise (forward) | Removes noise (reverse) |
| **Starts with** | A real image | Pure random noise |
| **What happens** | Add noise; learn to spot it | Remove noise; add detail |
| **Ends with** | A model that can denoise | A brand-new image |
